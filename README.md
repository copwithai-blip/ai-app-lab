# 🚀 AI App Lab

Small apps, built fast, with AI as my co-pilot.

I'm a tech geek who loves AI, apps, and anything techy. This repo is my starting point: a place to collect the little tools I build and the workflow I use to ship them from my phone.

## 🧰 My Workflow

1. **Idea** → describe the app to an AI assistant
2. **Code** → generate a single `index.html` file (HTML + CSS + JavaScript)
3. **Host** → deploy it free on Netlify or GitHub Pages
4. **Package** → convert the live site into an Android app with WebIntoAPK
5. **Improve** → test on my phone, tweak, repeat

Full steps are in [WORKFLOW.md](WORKFLOW.md).
